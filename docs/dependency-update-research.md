# Dependency update research

Research checked against package registries and official project release notes on 2026-10-11. The project remains on Nuxt 4.6.1, Vite 8/Rolldown, Node `^22.22.3 || ^24.15.0 || >=26.0.0`, and Tailwind CSS 4.3.3. `pnpm outdated --include-github-actions` reports only TypeScript 7.0.2 after the selected updates. pnpm's outdated command covers direct packages and workflow actions; `pnpm update --no-save --lockfile-only` refreshed compatible transitive resolutions without changing declared ranges.

## Intentionally unchanged or removed

- **TypeScript 6.0.3:** TypeScript 7.0.2 is the latest stable version, but it is a new Go implementation and a major toolchain boundary. Vue Language Tools still has an open issue for TypeScript 7 support, with 7.1 support on its roadmap. Retain TypeScript 6 until `vue-tsc` and Nuxt support is explicit and verified.
- **Heroicons 1.2.3:** no newer version was available; retain because `GeneratorPreview.vue`, `LogoControls.vue`, and `ColorInput.vue` use its icons.
- **`@nuxt/test-utils` 4.3.3:** current and still required by test runtime/config imports. Removed only the production `@nuxt/test-utils/module` registration; application code does not use module-only behavior and all tests pass.
- **`@nuxt/image` 2.0.0:** removed after confirming there is no `<NuxtImg>`, `<NuxtPicture>`, `useImage`, or `$img` usage. Removed its module registration and unused `image.format` config. Existing remote `<img>` content comes directly from the API.
- **pnpm 12:** deferred because its Rust rewrite has separate install/link behavior and lockfile implications.
- **Transitive notices:** pnpm still reports deprecated `glob@10.5.0` through `archiver-utils` → `archiver` → Nuxt/Nitro; there is no direct manifest dependency to update safely. Nuxt UI 4.11.3 also resolves optional Tiptap editor packages at 3.23.4 and 3.31.4, producing peer warnings. The app does not use the editor, so no overrides or unnecessary root dependencies were added.

## Measurements and verification

Production measurements used Node 24.21.0, the same `pnpm run build` command, and three sequential runs on this workstation. JavaScript gzip values sum per-file gzip output at level 9. Browser timings came from Chrome Resource Timing in one before and one after run; they are directional because external API latency varies.

| Metric                       |                                                                                Before |                                        After |                              Change |
| ---------------------------- | ------------------------------------------------------------------------------------: | -------------------------------------------: | ----------------------------------: |
| `nuxt generate` median       |                                                         11.97 s (11.83, 11.97, 12.10) |                11.44 s (11.30, 11.44, 11.48) |                               −4.4% |
| Generated JavaScript         |                                              15 files, 640,655 B raw / 204,022 B gzip |     15 files, 671,238 B raw / 211,958 B gzip |              +4.8% raw / +3.9% gzip |
| Homepage HTML / Nuxt payload |                                                                       29,665 B / 69 B |                              30,722 B / 69 B |    HTML +1,057 B; payload unchanged |
| Homepage MCBanners requests  |                                          3 example banner images; no JSON API request | 3 example banner images; no JSON API request |                           unchanged |
| Builder initialization       | 1 validation + 1 defaults + 1 constants + 1 preview request; ~536 ms to first preview |    Same 4 requests; ~521 ms to first preview | unchanged requests; −15 ms observed |
| One theme customization      |                                                          1 additional preview request |                 1 additional preview request |                           unchanged |

Browser smoke checks passed with both static serving and `wrangler pages dev`: homepage rendered and hydrated, all three example images loaded, resource validation navigated to the builder, initial and customized previews loaded, and the save action remained available. Save payload behavior is covered by `tests/nuxt/default-store.nuxt.spec.ts`; no persistent live save was created. Wrangler served the generated homepage with HTTP 200. Verification also passed `pnpm install --frozen-lockfile`, lint, formatting, typecheck, all 41 tests, and three production builds. Lint reports nine existing non-failing `vue/html-self-closing` warnings.
