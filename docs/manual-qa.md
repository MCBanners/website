# Manual QA Checklist

Use this checklist for the current `/` to `/builder` product flow.

- Homepage loads.
- Resource source validates and opens `/builder`.
- Author source validates and opens `/builder`.
- Server source validates and opens `/builder`.
- Invalid input shows an error and stays on `/`.
- Direct `/builder` visit without an active source redirects to `/`.
- Brand click resets the selected source and returns to `/`.
- Change Source action resets the selected source and returns to `/`.
- Design controls update the preview.
- Advanced controls update the preview.
- Save Banner returns a saved URL.
- Copy saved URL writes the saved URL.
- Copy embed output writes Markdown, BBCode, or HTML output.
- `/resources`, `/authors`, and `/servers` redirect to `/`.
- Production build preview loads the generated static app.
